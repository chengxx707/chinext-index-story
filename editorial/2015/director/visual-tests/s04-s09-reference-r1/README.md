## 两张参考如何落到画面

- **第一张的黑底、琥珀点阵地球和局部暖光。** 三帧采用相同的低亮点阵地球，把明亮范围集中在球面一侧，K 线从前景穿过，两个极值才有更亮的暖金。
- **第二张的蓝色后景和清晰的前景图表。** 密集推进帧在右下与远层留一层低对比钢蓝，账户题签、日期、红涨绿跌的真实日 K 和细红时间轨各有独立层级。
- **时间轨的年标。** 起点独显 2012。行情推进后依次显示 2013、2014、2015，低点基准继续写在底部涨幅轨上。

[同一时点的上一版与本版对照](reference-comparison.jpg)。两张参考原图见对话中的内嵌图片。并排文件左侧为原方案实帧，右侧为本次修订，两侧都标明版本。

**导演确认点**｜建议确立这一版的黑底、琥珀点阵和较淡的后景。确认后再制作 390 像素、20 秒的短样片，让行情运动带节奏，并核对题签在原速下的接力。
