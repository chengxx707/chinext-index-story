# 创业板指2015历史叙事架构 V1.0

状态：导演结构候选；用户已确认金融纪录片式主导（A）及“阶段低点后继续呈现反弹与修复”（A）。  
事实口径：方案A（T1/T2/T3）。  
建议章节时长：Beat Sheet预算约226秒（3分46秒），允许在阅读测试和连续播放后调整；不是冻结时长。

## 1. 本章要让观众理解什么

2015年创业板不是一条从3982点跌到1797点的单向曲线。它经历了参与度和估值扩张、六月高位转折、七月集中稳定措施与强劲反弹、七月末再次下挫、八月宏观与市场压力、九月急跌后的多次反弹与回落，随后进入十月至十一月的修复。

主问题：
- 上涨阶段，市场参与度、代表性企业和资金环境呈现什么状态？
- 高位转折后，市场和监管层分别出现了哪些行动？
- 为什么反弹不等于风险已经解除？
- 9月低点之后，市场如何反复修复？

不回答“哪项政策导致哪次涨跌”，不把某一天直接命名为最终市场底。

## 2. 六幕结构

### 第一幕：狂热正在形成（4—5月）
主线：开户制度变化、开户账户增加、代表性企业估值与创业板行情扩张。
观众理解：市场参与度和企业估值都在变化；账户数不等于独立投资者人数，企业市值不等于指数权重。
主视觉：参与度数字 → 乐视网企业估值场景 → 回到创业板K线。
候选素材：
- 4月13日起A股“一人一户”限制放开；
- 4月20—24日新增A股账户413.03万户（统计周，不是创业板开户数，也不是独立人数）；
- 5月13日乐视网收盘总市值超过1500亿元（V1.0.1采用的双同期报道口径）。
导演处理：不要把这些全部做成左上角新闻标签。用参与度—企业—指数三个视角接力。

### 第二幕：冲顶与第一次失速（6月）
主线：6月3日最高收盘3982.25；6月5日盘中高点4037.96；高位反复，6月中下旬快速回落。
观众理解：盘中高点与收盘高点不同；行情从高位开始失速，不用单一事件解释整个下跌。
冻结日线锚点：
- 2015-06-03 close 3982.25，high 4011.04；
- 2015-06-05 high 4037.96，close 3885.83；
- 2015-06-12 close 3899.71；
- 2015-06-19 close 3314.98；
- 2015-06-26 close 2920.70。
事件背景：6月12日证监会公开答问／外部接入管理背景；6月融资环境作为事后回顾性背景，不上屏未经复核的精确余额。
导演处理：高点命中时全画面短暂交给关键点位；回落开始后镜头切回宽景，让观众看到跌幅是一段路径。

### 第三幕：稳定措施集中出现（6月底—7月初）
主线：周末／盘后政策与市场措施密集出现；事件时间与交易时间分离。
观众理解：市场下跌过程中出现多项稳定措施；公告承诺、政策安排、实施日期不能混为一谈。
主视觉：事件接管（中央序列），后方K线按真实市场状态冻结或继续。
候选事件：
- 6月27日周末公布降息与定向降准，6月28日起实施；
- 7月4日21家券商承诺不低于1200亿元投资蓝筹ETF（承诺，不等于已完成买入，更不是直接买创业板）；
- 7月4日晚28家已获IPO批文公司暂缓发行；
- 7月5日证监会公告：央行将给予证金公司多种形式流动性支持。
导演处理：事件卡采用中央累积序列，最多三层可读层级；前项退为背景。行情不能被画成政策箭头直接推动。

### 第四幕：反弹与再次失控（7月）
主线：7月7日至23日强劲反弹，随后7月27日再度大幅下跌。
冻结日线：
- 7月7日收盘2352.01；
- 7月23日收盘2967.95；
- 区间收盘涨幅+26.19%；
- 7月27日收盘2683.45，单日−7.40%。
主视觉：政策序列退场 → K线反弹主导 → +26.19%阶段结算 → 7月27日突然冲击−7.40%。
导演处理：+26.19%明确7月7日至7月23日收盘区间；7月27日用真实日K和跌幅表达，不伪造盘中连续路径。

### 第五幕：第二轮冲击（8月）
主线：汇率机制调整、PMI、全球风险环境、连续下跌和盘后降息降准。
观众理解：外部宏观背景与国内市场压力同时存在；事件先后必须清楚，但不能把时间相邻写成确定因果。
候选节点：
- 8月11日人民币中间价报价机制调整；
- 8月18日创业板单日−6.08%；
- 8月21日财新制造业PMI初值47.1，09:43发布（晚于A股09:30开盘）；
- 8月21、24、25日三个连续完整向下缺口（由冻结OHLC定义）；
- 8月24日收盘2152.61，单日−8.08%；
- 8月25日收盘1990.71，单日−7.52%，收盘跌破2000点；
- 8月25日18:15:34盘后公布降息降准安排；降息8月26日起实施，降准9月6日起实施；
- 8月26日创业板继续下跌−5.06%。
主视觉：宏观时间层 → K线跳空 → 8月24日真实现场照片 → 8月25日跌破2000 → 盘后公告接管 → 8月26日继续下跌。
导演处理：照片是现场证据，不作情绪推断；盘后公告必须在市场收盘冻结后出现；实施日期作为未来日历标签，不提前生成未来K线。

### 第六幕：寻找底部与修复（9月—11月）
主线：阶段低点之后并非直线上升，而是强反弹、回落、再反弹，随后进入更长修复区间。
观众理解：市场底不能仅凭一个最低点确认；价格反弹、成交变化和ETF份额变化是不同观察维度。
冻结日线关键锚点：
- 9月2日盘中最低1779.18，收盘1855.03；
- 9月15日盘中最低1794.29，收盘1797.56（本窗口最低收盘）；
- 9月16日收盘1926.25，单日+7.16%；
- 9月17日收盘1933.30，单日+0.37%；
- 9月21日收盘2079.06，单日+4.83%；
- 9月25日收盘2020.97，单日−4.06%；
- 9月28日收盘2122.26，单日+5.01%；
- 9月29日收盘2098.57，单日−1.12%；
- 10月8日收盘2190.31，单日+5.17%；
- 10月12日收盘2316.78，单日+4.52%；
- 11月25日收盘2897.57，相对9月15日收盘+61.19%。
同期市场结构素材：
- 9月7日至22日，易方达创业板ETF份额由12.37亿份升至18.07亿份，增加46.08%；该指标反映ETF份额变化，不直接等同净申购金额，也不证明其导致指数反弹。
- 9月21日同期报道指出成交量仍处低位；9月28日创业板上涨时，两市成交额继续缩量至4044亿元（同期报道口径）。
主视觉：阶段低点 → 9月16日突然反弹 → 9月21日再次上行 → 9月25日回落 → 9月28日再反弹 → ETF份额作为市场结构侧视 → 10月/11月修复全景。
导演处理：不打“市场底已确认”；可用“阶段最低收盘”“反弹与修复”作为限定表述。最终以11月25日收盘2897.57和相对9月15日+61.19%收束本章节，保留后续历史接口。

## 3. 关键叙事逻辑

本章不是“政策救市→市场反弹”的因果故事，而是以下并置的历史观察：
- 市场参与度与企业估值扩张；
- 指数高位转折与融资环境背景；
- 稳定市场措施集中出现；
- 随后的反弹与再度下跌；
- 宏观冲击与国内市场急跌；
- 低点后的多次反弹、回落及修复。

所有政策事件使用“同期发生”“随后”“公告后”“实施日”等时间关系，不使用“因此”“导致”“救市成功”等未经证明的因果表达。

## 4. 结尾设计

结尾不是单独停在1797.56，而是先回看：
- 6月3日最高收盘3982.25；
- 9月15日阶段最低收盘1797.56；
- 11月25日收盘2897.57；
- 9月15日至11月25日收盘涨幅+61.19%。

画面分三步：
1. 全景回看6月高点至9月低点的完整下跌路径；
2. 镜头沿真实日K推进，呈现9月反复和10—11月修复；
3. 阶段结算显示+61.19%，注明“9/15—11/25收盘区间”，保留“阶段修复”而非“牛市重启／市场底确认”的文字。

情绪不是大团圆，而是“经历剧烈冲击后，市场开始修复，但不确定性仍在”。

## 5. 事实与设计分层

- 冻结日线OHLC和由其计算的涨跌幅：T1。
- 政策公告、ETF份额、宏观数据：按原始来源与同期可靠来源核验后，T1/T2分层。
- “狂热”“失速”“反复筑底”“修复”等章节名：T3编辑语言，不冒充官方分类。
- “市场底”只有在有明确事后定义和足够证据时才可使用；本候选不用它作确定标签。
