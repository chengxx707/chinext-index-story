# 导演分镜与实现边界

目标是连续经历行情。事件文字有稳定阅读时间，行情在一般事件之后可以继续推进；盘后、周末、峰谷结算才冻结市场时钟。

## 统一画面

- 1080×1920，30fps，静音。继续使用批准的画面资源与字体，标题只写“创业板指（399006）”。
- 顶部0—180px放标题、当日日期与收盘；约195—390px为事件文字留白；主图约420—1300px；地球下缘与红色时间轨位于下半区，活动轨约1830px。坐标是候选布局约束，需实际排版复查。
- 事件主字建议44—54px，来源行至少28—30px；极值数字可88—112px。禁用大面积金属字、粗立体阴影和遮住日K的黑卡。
- 金色限于极值小光点与事件细边，红色用于时间轨/局部地球反光。地球使用既有夜景纹理、蓝色大气与局部红色水面反射，不新增无关装饰。
- 一个画面只有一个主读点。事件、数字、照片的主次依次交接；常驻HUD不抢主文案。

## 三种时间角色

1. `market_clock` 是唯一市场播放头，日期、OHLC、收盘和活动轨从同一真实交易行计算。摄影机的平滑位置不生成虚假的收盘值。
2. `event_clock` 保留公告日、网页时点、生效日、统计周等实际角色。周末和盘后只推进事件日历，不创造新蜡烛。
3. `historical_observation` / `retrospective_statistic` 是回看历史的注解，不声称这些数据当时已经公开。六月两融规模必须保留“事后统计回顾”。

## 可执行的镜头规则

- `director_timeline.json` 记录每个命中帧、整数帧区间、日期关键帧、文本进入与退出、极值真实坐标、缺口上下边和相机目标。它是对现有record Schema的伴随配置，不得被导入器忽略。
- 跨镜头继承投影与运动速度，至少位置和速度连续；普通行情推进不黑屏、不重新从零启动相机。单镜缩放改变整个坐标系，绝不单独拉高/放大某根K。
- 阅读期间纵向比例稳定，文字固定在留白区，连接线跟随历史蜡烛。当前HUD日期可继续前行，事件标签自己的历史日期不能跟着变。
- 极值点先局部亮起0.25—0.4秒，再连到比较端点；收盘对收盘，盘中影线对盘中影线。禁止把4037.96与1797.56混算成收盘回撤。
- 8月21、24、25日缺口使用固定近景范围，绘制前日最低到当日最高之间的真实空白；8月26日存在区间重叠，不编号为第四个完整缺口。
- 地球轨道节点与事件/关键点命中使用同一帧，约0.7秒柔和反射脉冲。它只是视觉强调，不表示全球市场受该事件影响。
- 一条活动轨：峰值停留结束前按2012-12-03收盘593.66为基准显示涨幅；之后相对2015-06-03收盘3982.25显示当前回撤。七月反弹使轨回退，9月15日才到−54.86%。轨不是情绪指数、账户收益或时间进度。
- 8月24日照片镜头仅用真实昆明原图（PHOTO-20150824-01），等比contain，不生成/补画人物；主图缩为下方行情条，日期与2152.61仍可追溯，地球与轨道保持。5秒后连续回主图。

## 能力边界与审片

候选文件检查可以验证数据、时序和引用；相机连续、文字遮挡、地球质感与观众阅读体验必须看真实渲染。缺照片文件时不生成文字页冒充相册，可继续独立的主体预览并明确缺镜。

本轮不重写渲染器，也不生成视频。Codex需先做能力检查/最小适配，再输出本167秒连续预览和少量诊断帧；不要再次只选一个峰值片段打磨。
