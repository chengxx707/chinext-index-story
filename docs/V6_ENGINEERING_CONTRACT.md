# 创业板指 V6 · 导演叙事增强版工程契约 V0.1

> 状态：供 Codex 直接执行的工程契约；不是最终成片脚本。  
> 基线工程：`chinext_v5_engine`。  
> 样片范围：2012-09-03 至 2015-06-19。  
> 目标时长：约 22 秒，竖屏 720×1280，30 fps，无音乐。  
> 视觉母版：`assets/reference/approved_visual_reference.png`。

---

## 0. 本轮阶段定位

V5 已经验证了以下功能：

- 唯一时间游标驱动日期、日 K、事件、时间轴和阶段数据；
- 真实 OHLC 实心蜡烛；
- 远景、中景、近景与快慢变化；
- 事件日期与对应日 K、地球时间节点联动；
- 2012 低点与 2015 高点的命中；
- 3982.25 历史水平线持续保留。

V6 不直接承担“最终发布级美术封版”。V6 的验收目标是：

1. **导演叙事通过**：2013—2015 的上涨不再像无解释的快速爬坡；
2. **信息密度通过**：除刻意留白外，画面不应长时间只有 K 线独自运行；
3. **状态逻辑通过**：同一个指数只显示一根当前有效的阶段状态轨；
4. **美术进入可审美验收级**：事件、地球、时间轴、K 线达到“方向正确且可继续精修”，但不要求一次做到最终发布级。

V7 才承担最终字体微调、光影精修、音乐、音效、混音和全片统一。

## 1. 唯一事实源与硬边界

### 1.1 唯一行情源

- `data/cyb_daily.csv`
- 所有日期、开盘、最高、最低、收盘、涨跌幅均由 CSV 读取。
- 所有画面状态继续由同一个 `playhead_index / playheadDate` 驱动。

### 1.2 样片使用的事实节点

- 2012-10-30：首批创业板公司控股股东三年锁定期届满；
- 2012-11-16：IPO 实质暂停，至 2014 年 1 月重启；
- 2012-12-03：收盘 593.66，全样本最低收盘；
- 2013-07-24：华谊兄弟并购手游公司相关事件；
- 2013 年创业板指全年 +82.73%；
- 2014-01-08：IPO 重启的画面日期锚点；
- 2015-04-13：一人多户放开；
- 2015-04-24：单周新开 A 股账户 413.03 万户；
- 2015-06-03：收盘 3982.25，阶段高点；
- 2015-06-19：收盘 3314.98，较 2015-06-03 收盘回撤约 -16.76%。

### 1.3 上屏边界

- 事件只写“日期 + 事件名 / 已核验数字”，不写“因为、导致、受益于、引发、所以”。
- `2013—2015 移动互联网与并购潮`属于阶段背景，不作为单因解释。
- `2015.06 场外配资清理`保留在配置草案中但默认关闭；在官方出处和精确文件日期补齐前，不得进入发布候选。
- 不出现预测、买卖建议、支撑、压力、见顶、见底、突破、抄底等词。
- 关键点位可写“全样本最低收盘”“阶段高点”，不写交易判断。

## 2. V6 叙事主线

V6 不是把事件卡塞进 K 线，而是建立以下连续理解：

```text
2012 供给与发行环境变化
→ 2012.12 全样本最低收盘
→ 2013—2015 移动互联网与并购潮的阶段背景
→ 2013 公司事件与年度大涨幅
→ 2014 IPO 重启
→ 2015 开户潮连续升温
→ 2015.06.03 抵达阶段高点
→ 高点之后立即进入真实回撤
```

观众不需要被告知单一因果，但应该能感受到：行情速度变化与一组同期制度、产业和市场现象共同发生。

### 3.2 信息密度规则

- 除关键点命中后的呼吸时间外，不允许连续 **1.5 秒以上**只有 K 线平移而没有任何有意义的信息变化。
- “有意义的信息变化”包括：镜头远近、时间速度变化、事件预热/命中、阶段背景、年度数据、状态轨切换、关键点位、历史水平线。
- 同一时刻只允许一个主信息焦点；不能同时弹两张大事件卡。

## 4. 状态轨逻辑：一根活动轨，不再两根并列实时轴

### 4.1 设计结论

V5 的两根常驻轨容易让观众误以为上涨与回撤是两个同时运行的独立指标。V6 改成：

> **一根当前活动的阶段轨 + 已完成阶段的小型里程碑徽标。**

### 4.2 三种模式

#### 模式 A：2010 高点 → 2012 低点

```text
label = 阶段回撤
value = current_close / 1232.98 - 1
progress = abs(value) / 0.5185
color = 冷蓝
```

到 2012-12-03：

- 轨道锁定 `-51.85%`；
- 缩成一个小里程碑徽标，停靠在 2012 时间节点附近；
- 活动轨进入模式 B。

#### 模式 B：2012 低点 → 2015 高点

```text
label = 阶段上涨
value = current_close / 593.66 - 1
progress = value / 5.7080
color = 红色
```

行情回调时，进度必须后退；到 2015-06-03：

- 轨道锁定 `+570.80%`；
- 缩成小型里程碑徽标；
- 命中停顿后，活动轨进入模式 C。

#### 模式 C：2015 高点之后

```text
label = 高点后回撤
value = current_close / 3982.25 - 1
progress = abs(value) / 0.5486
color = 冷蓝
```

在 V6 样片末日 2015-06-19，显示约 `-16.76%`。

### 4.3 动画

- 模式切换使用 0.35–0.50 秒形态变换，不允许两根完整进度条同时常驻。
- 轨道可放在地球时间轴下方或与其形成平行弧线，禁止回到 PPT 三栏统计面板。
- 已完成的 `-51.85%` 和 `+570.80%`以小型徽标或节点文字留痕，不再占据整条轨道。

## 5. 事件体系：主事件、辅助事件、阶段背景

### 5.1 主事件卡

用于：2012 解禁、2012 IPO 暂停、2013 华谊并购、2014 IPO 重启、2015 开户潮。

视觉规范：

- 无重金属、无浮雕、无大面积金框；
- 透明黑玻璃底，背景局部模糊；
- 1 px 暖金发丝边，只允许左边或底边出现，不包围整块卡片；
- 红色日期胶囊；
- 白色无衬线主文字；
- 暖金只用于精细边缘和关键数值；
- 卡片进入：8–12 px 位移 + 淡入 + 细线绘制；
- 事件退场后，只在时间轴留下小节点。

### 5.2 辅助事件

用于：2015-04-13 一人多户放开、2013 年度 +82.73%。

- 不使用完整卡片；
- 以一行短文字、年份角标或轻量数字出现；
- 停留 0.6–1.0 秒；
- 不抢主事件和关键点位的视觉中心。

### 5.3 阶段背景

`2013—2015 移动互联网 / 并购潮`

- 是阶段语境，不是单因解释；
- 采用低对比细字或短暂背景带；
- 不直接连到某一根 K 线；
- 只在 2013 前段至 2014 后段出现，避免覆盖 2015 高点。

### 5.4 事件连接

- 事件日期必须同时点亮时间轴节点和当日日 K；
- 使用短促、低亮度的“时间节点 → 图表下沿 → 当日日 K”折线路径；
- 不允许出现贯穿全图、像趋势线或因果箭头的长斜线；
- 连接线在 0.35–0.55 秒后淡出，卡片可继续短暂停留。

## 6. K 线与摄影机美化

### 6.1 真实比例

- 必须继续使用真实 open/high/low/close；
- 不允许单独拉伸关键蜡烛；
- 大小变化只能来自可视交易日窗口与纵轴取景。

### 6.2 摄影机

从 V5 的连续 keyframe 改为语义化 `camera_shots`：

```json
{
  "id": "accounts_2015_closeup",
  "start_t": 13.8,
  "end_t": 15.45,
  "visible_days_start": 90,
  "visible_days_end": 52,
  "current_x_start": 0.76,
  "current_x_end": 0.68,
  "y_policy": "lookahead_locked",
  "focus_date": "2015-04-24"
}
```

`y_policy` 至少支持：

- `follow_window`：普通远景；
- `lookahead_locked`：事件展示期间，纵轴范围用该镜头首尾加少量前瞻统一计算，避免读字时画面呼吸；
- `critical_anchor`：关键点位附近，保证锚点处于指定视觉区域。

### 6.3 K 线画质

- 图表和事件层使用 2× supersampling 后缩回 720×1280；
- 红：`#FF3D38` 附近；绿：`#18CF88` 附近；
- 实体边缘清晰，影线不糊；
- 普通蜡烛不持续发光；仅当前 1–2 根和关键蜡烛有轻微 bloom；
- 近景实体宽度约 10–16 px，中景 5–9 px，远景 2–4 px；
- 网格不画外框，线条向四周渐隐；
- 星点数量减少，背景不应像随机粒子 Demo。

## 7. 地球与时间轴美术升级

### 7.1 分层

基于 `assets/reference/earth_body_reference.png`构造至少四层：

1. 地球主体；
2. 蓝色大气层边缘；
3. 暖色城市灯光 bloom；
4. 时间节点产生的红色反射与波纹。

### 7.2 节点光照

事件或年份命中时：

- 时间轴节点产生 2 层红色光圈；
- 地球表面出现一个被 alpha mask 裁切的椭圆红光；
- 红光沿表面有轻微横向波纹；
- 城市灯光只略微受到红色反射，不改变整个地球色相；
- 不使用三角形光束、重型扫描器或大面积霓虹。

### 7.3 时间轴

- 弧线贴合地球边缘；
- 未经过部分保持暗红；经过部分为清晰红光；
- 年份节点只显示与当前阶段相关的 2012、2013、2014、2015，避免样片里出现未来 2018/2021 干扰；
- 事件小节点与年份节点区分大小；
- 当前日期光点必须是最亮元素之一，但不能压过关键 K 线金光。

## 12. V6 验收清单

- [ ] 所有元素仍由一个时间游标驱动；
- [ ] 事件、日期、日 K、时间节点同步；
- [ ] 状态轨只有一根处于活动状态；
