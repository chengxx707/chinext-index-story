只读审查，未改源码、未渲染新候选。数值从已生成的V1渲染清单的派生配置重建SceneModel帧状态，当前点坐标按原绘图公式换算为1080像素。

## 结论

1. 市场日期和价格在接缝相同，并不代表画面位置连续。每node独立新建SceneModel（film_renderer.py:69），相机blend只在该model内部执行（model.py:294–322）。新node首帧没有前镜头状态。
2. 12秒点当前价纵跳+87px，17秒+104px，25秒−112px，59秒−70px，90秒−124px。17秒可视范围从100日硬切36日，25秒又回100日；59秒100→55日，78秒55→100日。
3. 市场playhead为浮点，但窗口和当前索引被取整（model.py:244），绘图坐标只读整数窗口（drawing.py:239）。同一真实交易日内，锁定轴范围时K线几何不运动，只在下一天跳一步。
4. S13的整片64.3—74.03秒，同一08.25的K线几何保持约9.73秒；S11有6.1秒和5.7秒固定段；S15最后7秒全停。以上不是整幅视频冻结，文字和光效仍可能变化。
5. 用户所见黑影来自内容卡实底：event卡87%不透明、宽401逻辑像素（图表宽678）；quote/doc卡93%不透明、宽619。quote固定高度使大约44%图表面积被压暗，短引文也有大黑底。
6. 整张content_layer连阶段上下文一起每拍fade-out/fade-in，上一拍退出0.4s、下一拍入场0.3s，几乎每段都经历读屏区减亮/空档。阶段上下文也重复闪退。
7. 高低记忆只有2015高点水平线、S09/S15局部金光和百分比/阶段轨。没有2012低点端点、两端同步点亮、跨时间比较路径。2012低点早于36日近景窗口，不能直接画一个假坐标连过去。

## 优先修法

- 首先把镜头状态从事实节点中独立：连续carry前镜头的浮点水平窗口、y范围与视觉时钟，缩放用0.8—1.2秒过渡，消除接缝瞬移。分段缓存不应成为硬切边界。
- 保留真实OHLC和真实日期/收盘，浮点只用于视窗、坐标变换与揭示进度；不要平滑出虚构收盘。
- 移除主片大面积不透明信息底板，改为少量文字、短引线/窄色条和局部字形阴影，保留价格图完整可见；不要用把K线画到文字上方的方式掩盖遮挡。
- 阶段上下文独立持续，正文采用轻位移/交接，减少整块卡片同时熄灭；政策精确冻结拍保留事实日，可做温和的相机运动。
- 高点重音时恢复2012低点记忆标签，通过时间轨的真实日期锚点或明确的历史比较inset做两端点亮→光线迁移→+570.80%结算；它是价格比较，不是政策因果箭头。
