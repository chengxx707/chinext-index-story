## GPT已裁定的内容要求

### B13：PMI时间线
- 同时显示“09:30｜A股开盘”和“09:43:10｜财新网页刊发”。
- PMI初值为47.1。
- 09:43:10只代表所引用网页的刊发时间；首次发布时间仍未核实。
- 不得写成“PMI首次公布晚于开盘”，不得将网页时间绑定为精确盘中价格点，不得伪造分钟级K线。

### B17：两项T2信息分开呈现
1. **易方达创业板ETF份额**：9/7—22观察窗，12.37亿份→18.07亿份，+46.08%；9/25同期报道；标注“据中国证券报援引深交所数据”。不得称净流入或资金流入，不得解释为指数反弹原因。
2. **沪深两市成交额**：9/28收盘后展示4044亿元；明确是沪深两市合计，不是创业板成交额。

两项不得同屏，也不得添加因果箭头。若现有B17时长不足，应提出延长或压缩普通行情段的方案，不得牺牲阅读时间。
