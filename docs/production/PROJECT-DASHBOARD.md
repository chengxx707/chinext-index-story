## 信息严谨程度：建议采用三层标准

| 层级 | 内容类型 | 放行标准 |
|---|---|---|
| T1 上屏事实 | 日期、点位、百分比、账户数、政策条款、直接引语 | 优先一手原始文件；无法取得时至少两个相互独立的可靠同期来源。明确统计口径、日期精度、公告/报道/实施/交易锚点。关键数字须由冻结数据或原件复算。 |
| T2 历史背景 | 市场参与度、产业环境、机构措施、企业背景 | 至少一个权威来源，重要或有争议的陈述需第二来源交叉支持；不得把事后框架冒充同期判断。 |
| T3 编辑解释 | 阶段命名、叙事连接、市场理解 | 可以由GPT提出，但必须标记为编辑解释；不得将时间相邻写成因果，不得伪装成历史原话。 |

### 建议的放行规则
- 核心屏幕数字和直接引语按T1执行。
- 背景字幕按T2执行。
- 叙事判断按T3执行。
- 证据不足的内容可以留在研究档案，不必强行塞入视频。
- 不以“所有39条都上屏”为目标；以“重要内容有充分证据、叙事完整”为目标。
