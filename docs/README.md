## 目录分工

| 目录 | 保存内容 |
|---|---|
| `production/` | 对外审阅的正式路线图、生产稿与后续进度 |
| `research/` | 事件、素材、来源核对和事实候选；不直接当运行时启用配置 |
| `source/` | 用户原始脚本与研究文档，保留原文 |
| 本目录中的历史合同/审阅记录 | V5/V6开发依据；与最新要求冲突时以当前生产稿和制作规范为准 |

来源原件保存在 `assets/source_documents/`，提取正文保存在 `data/source_text/`；机器主表保存在 `config/production/`。视频、关键帧、缓存等生成物统一放在忽略的 `output/`，不与可编辑输入混存。
