# V6 人工评审清单

## 第一轮：不看美术，只看叙事

- [ ] 2012 低点之前，我能理解当前是在回撤阶段；
- [ ] 低点命中后，状态轨明确切换到上涨阶段；
- [ ] 2013—2015 不再是一段无解释的快速爬坡；
- [ ] 2014 不会一闪而过到完全无法感知；
- [ ] 2015 开户潮前后，K线、日期、数字和时间轴明显联动；
- [ ] 抵达 3982.25 前有持续减速，不是突然弹出高点；
- [ ] 高点后能清晰看到真实大振幅和回撤。

## 第二轮：看逻辑

- [ ] 任意时刻只有一根完整活动状态轨；
- [ ] 上涨过程中回调时，红轨会后退；
- [ ] 高点后同一轨转为回撤模式；
- [ ] 历史阶段结果以小里程碑留痕，而不是第二根常驻轴；
- [ ] 事件没有被视觉上表达成单因解释；
- [ ] 所有事件都对应到真实日期与日K。

## 第三轮：看美术方向

- [ ] 标题仍是小体量无衬线版本；
- [ ] 事件卡比 V5 精致，但没有重金属感；
- [ ] 暖金发丝边是细节，不是大金框；
- [ ] 地球有清晰大气层与城市灯光；
- [ ] 红色节点会在地球表面产生轻微反射和波纹；
- [ ] K线近景的实体和影线足够好看；
- [ ] 网格、星点、装饰不抢真实信息；
- [ ] 整体质感接近视觉母版，而非开发者 Demo。

## 第四轮：是否进入 V7

只有前三轮全部通过，才进入：音乐、音效、最终字体与间距、完整色彩校准、全片 2010—2026 扩展。
