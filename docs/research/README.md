**证据边界**

35秒附近是2015年8月24日，36秒附近到9月初。8月24、25日存在整日价格区间不重叠的真实向下缺口；8月26日是低开下跌，不能称为同样的完整缺口。6月3日高点之后有高位反复，6月12日收盘只较其低约2.07%，不应把后续三个月剪成没有层次的连续崩跌。

政策公告、实施、实际资金操作、价格反应分开记录；候选措施早于9月15日低点，不能叙述为最低点当天才启动。情绪分为可复算市场状态、可能机制、同期报道描述，不虚构情绪指数或把下跌等同所有人恐慌。
