**分期应有两条轴。**

主轴是价格波段：上涨、下跌、反弹、再调整，这是观众在图上实际看到的过程。副轴是产业与制度背景：它回答当时市场在关注什么，但不能代替价格路径。

用户的更新清单第5节确实写了三段产业框架，归因到开源证券复盘、每经引用：2013—2015移动互联网与并购潮，2019—2021新能源，2023—2026 AI算力。原件没有直接链接，应标记为已提供的二手研究框架，后续可补出处；它不是官方唯一的市场分期，也不能据此断言每一段指数上涨都由该产业造成。

尤其2023年开始出现AI算力叙事，但创业板指的价格主轴仍在2021—2024调整中。两者可以在同一画面并存：淡色阶段背景条写产业语境，中央仍如实呈现指数回撤。不能为了让产业章节“顺”而把下跌剪成上涨。

这些阶段是样本内的编辑结构，不是交易信号或官方分期。原来的六章不必机械改成八章；八阶段可用于细分字幕和背景条，章节保持较少，避免为内容整理重做整个画面系统。

**每阶段固定四层，提升的是理解密度。**

1. 阶段背景：一条低对比文字，说明产业/制度语境，例如“2013—2015 移动互联网与并购潮”。它可以停留较久，不抢主焦点。
2. 价格节点：真实K线与关键收盘，显示当前这段究竟涨跌多少。2015“高点→九月低点→十一月反弹”必须让观众分别看懂。
3. 同期事件：政策、公司、市场现象混排。必要时把一组措施呈现成简洁时间带，避免每条都做大卡。
4. 有证据的市场描述：先用可复算事实，例如“单周开户超过400万”；需要“恐慌”“担忧”“追逐”等词时，用当时的报道或明确指标支撑，并标记为媒体/指标所反映的状态，而不是全体投资者的统一情绪。

四层不是同一帧同时铺满四类文字。同一时刻保留一个主信息焦点，其他层保持低亮度或暂时退场。也不要求每1.5秒弹卡。阶段背景与连贯解释可以填补机械平移，阅读速度仍是硬限制。

**2015段首先需要补齐的叙事链。**

当前42秒样片只把开户与高点讲得较完整，却将高点后的三个月压到8秒推进，再停在9月低点。观众看到连续跳空和极大回撤，却没有看到6—9月多次政策、稳定市场措施、阶段反弹和外部冲击的先后。这是结构性缺口，不是再随意加一两张事件卡就能解决。

应依序回答：

- 上涨阶段的参与增加与杠杆环境，有什么当时证据？
- 6月高点之后，最早的价格下跌与后续规则/清理措施各在何时？不能让6月13日左右的候选文件“解释”更早的6月3日高点。
- 6月底、7月的宏观流动性政策与专门稳定资本市场措施分别是什么？公布日、实施日、资金实际入市日需要区分。
- 7月是否曾阶段反弹，后来又怎样回落？不可以一条直落箭头跳到9月。
- 8月的汇率制度节点、8月24—26日行情与8月25日政策按怎样的顺序发生？同期外部冲击与国内杠杆调整的机制应分别有出处。
- 9月低点之前已经有哪些措施？不能把救市画成“刚好最低点当天才启动”，也不能用事后低点证明政策立刻奏效。

“救市”还要拆类型：降息降准是宏观流动性政策；券商、汇金、证金等稳定资本市场措施是另一类；IPO暂停、交易规则、停牌又是其他渠道。它们可处在同一条时间线上，但不能混成一个无日期的“国家队来了”。具体日期与措辞以本轮2015来源研究为准。
