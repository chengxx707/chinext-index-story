## 2. 高点之后下行：首先把时序讲对

本地创业板指阶段最高收盘为 **2015-06-03 / 3982.25**。6月12日收3899.71，较此高点仅低2.07%；6月15日当日跌5.22%，6月19日收3314.98，较高点回撤16.76%。这说明：

- 6月3日的阶段高点与6月中旬加剧的回撤应分开讲，不能用6月12日以后发布的监管事件倒推解释6月3日当天。
- 创业板与上证的高点日期不同，不宜把上证6月12日峰值套到创业板图上。
- “某一文件让创业板从6月3日开始下跌”没有得到现有证据支持。

可作为研究背景的多因素框架是：快速上涨后的高位分歧、杠杆头寸与风险暴露、监管变化、下跌中的追加担保/平仓与流动性压力。这里“可能形成反馈”是机制描述；没有杠杆存量、估值、资金流或因果识别数据，不能给各因素分配百分比，也不能断言某项监管是唯一原因。

建议上屏先展示能证明的状态：`高位剧烈波动`、`回撤扩大`、`两日连续向下跳空`；事件在补齐原文后加入。若需要“恐慌”“踩踏”等强情绪词，应引用当时权威报道并明确是当时的市场描述，不冒充测得的投资者情绪指数。

## 4. 到阶段低点有没有救市

候选历史链显示稳定措施早在6月底、7月和8月底即连续出现，**不能叙述为直到9月15日低点当天才开始救市**。需要补原文后，片子可呈现“措施逐步推出—行情出现反弹—随后仍有再度下跌—抵达样本内阶段低点”的过程。

本地数据还给出一个重要反例：8月25日宣布措施后，8月26日创业板仍跌5.06%；9月15日低点1797.56之后，至11月25日反弹至2897.57，约+61.19%。政策存在、市场立即止跌、后续反弹是否由某措施造成，是不同命题；前两项可分别核事实，最后一项没有在本研究中得到因果证明。

对9月15日当天有没有独立新措施，当前没有读到可支持的原文，不能据此断言“当天绝无措施”，也不能为了对齐低点而捏造一条。

## 5. 市场情绪如何进入片子

建议使用三级表达，强度与证据对应：

| 等级 | 示例 | 所需证据 |
|---|---|---|
| 直接行情状态 | `高位分歧加大`、`波动加剧`、`两日连续跳空` | 日K、日涨跌、区间数据，已能本地复算；“分歧”仍属叙事概括，不是情绪测量 |
| 资金与交易机制 | `杠杆资金面临平仓压力`、`市场流动性承压` | 当时监管通报、交易与融资数据、权威同期报道；当前待核 |
| 强情绪词 | `恐慌蔓延`、`信心脆弱`、`抢先卖出` | 明确当时报道/调查或可说明的代理指标，不仅由一根阴线推断所有人的心态 |

有依据的解释可以用一行“阶段背景”置于事件卡上方，事件本身仍写清日期；不要把一行背景连成指向极值的因果箭头。例：`高位调整与去杠杆期间`（待核机制背景）＋`2015.07 稳定市场措施密集推出`（逐条事实核完后可用）＋实际行情。全程仍可保持无声，用短句而不是整页分析。

## 6. 可先讨论的导演结构

2015段建议分成四个小阶段：

1. **开户潮与高位上行**：已经有A级用户材料的开户数字＋真实上涨；先让观众理解当时参与热度。
2. **高位调整与回撤扩大**：阶段高点后，真实回撤＋配资/杠杆背景的待核短句，避免一屏只看跌幅。
3. **稳定措施与剧烈反复**：6月底、7月政策响应＋反弹/再次下跌，不把“措施推出”直接剪成“已经结束下跌”。
4. **8月急跌与9月低点**：连续真实跳空＋外部市场背景、8月底措施，再抵达9月15日；结束时保留“不在同一天”的真实时间间隔。

这四段是视频叙事划分，不是金融学上的唯一周期分类。与全片“移动互联网/并购、新能源、AI算力”等产业阶段可构成上下两层：上层讲时代主题，下层讲眼前这轮行情经历的状态。两者不要争夺同一屏主焦点。
